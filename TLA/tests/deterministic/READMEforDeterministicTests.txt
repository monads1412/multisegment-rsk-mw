COMPREHENSIVE BOUNDED TLA+ TEST HARNESS
=======================================

Purpose
-------
These tests exhaustively check the two TLA+ implementations on every
multisegment inside a small finite universe.

The bounded tests are complementary to the randomized tests:
  - bounded tests check EVERY input inside small bounds
  - randomized tests sample inputs from a much larger universe

The two bounded test modules are:
  1. BoundedTests.tla      -> FormalizedCorollary.tla (sequence representation)
  2. BoundedBagTests.tla   -> BagFormalization.tla    (bag representation)


Required files
--------------
For the sequence tests:
  FormalizedCorollary.tla
  BoundedTests.tla
  BoundedTests.cfg
  tla2tools.jar

For the bag tests:
  BagFormalization.tla
  BoundedBagTests.tla
  BoundedBagTests.cfg
  tla2tools.jar


Bounds
------
Both test suites use:

  EndpointBound
      Every segment endpoint is restricted to
      -EndpointBound .. EndpointBound.

  MaxSegments
      Maximum total number of segment occurrences in a tested multisegment.

For example:

  EndpointBound = 1
  MaxSegments   = 2

tests every nonempty multisegment of at most 2 segments whose endpoints lie
between -1 and 1.


Run
---

Sequence implementation:

  java -cp tla2tools.jar tlc2.TLC -config BoundedTests.cfg BoundedTests.tla

If using the bounded-test shell script:

  bash run_bounded_tests.sh 1 2

where 1 is EndpointBound and 2 is MaxSegments.


Bag implementation:

  java -cp tla2tools.jar tlc2.TLC -config BoundedBagTests.cfg BoundedBagTests.tla

The values of EndpointBound and MaxSegments are set in BoundedBagTests.cfg.


What is checked: FormalizedCorollary
------------------------------------
BoundedTests.tla checks every generated sequence multisegment and verifies the
main constructions used by the formalization, including:

  - the bounded input representation and segment operations
  - depth, depth fibers, and admissible enumerations
  - distinguished indices and the i |-> i^vee permutation
  - transformed segments, l(m), and the derived multisegment m'
  - min(m) and the leading-sequence construction
  - m^cross, Delta^circle, K, and MW
  - Lemma 1
  - all three Corollary 3.4 formulations

Several constructions are also checked independently rather than only by
testing the final theorem statement.


What is checked: BagFormalization
---------------------------------
BoundedBagTests.tla checks every generated bag multisegment and verifies:

  - the bounded bag representation
  - StandardOrder
  - global-index coverage and multiplicities
  - admissible enumerations
  - Lemma 1
  - both bag formulations of Corollary 3.4


Exhaustive means exhaustive only inside the bounds
--------------------------------------------------
A PASS means that every multisegment generated by the chosen finite bounds
satisfied every enabled invariant.

Increasing EndpointBound or MaxSegments increases the number of states that
TLC must check.  In particular, increasing MaxSegments can make the expensive
depth and enumeration operations grow quickly.

The bounded tests therefore give complete coverage of a small universe, while
the randomized tests provide broader but non-exhaustive coverage of larger
inputs.
